# Project Statement

## Problem Statement
Manual inspection and basic image editing do not provide a unified workflow for analysing important visual features such as edges, corners, shapes, objects and regions. This project develops a computer vision application that performs common image-analysis operations through a single pipeline.

## Scope
The system accepts an image and performs preprocessing, edge detection, feature detection, shape/object analysis and K-Means image segmentation. It saves the generated results for inspection.

## Target Users
Students, beginners learning computer vision, and users who need a simple image-analysis demonstration tool.

## High-Level Features
- Image preprocessing and smoothing
- Canny edge detection
- Harris corner detection
- Contour-based shape detection
- Contour-based object detection
- K-Means image segmentation
- Saved output visualizations
